PDF Text Jump Viewer v3.0（ヒットページ連続表示版）

配置:
- index.html: リポジトリ直下へ上書き
- pdfs.json: 既存設定をそのまま利用
- PDF: indeedmarketreports/ 内

今回の追加機能:
- 横断検索でヒットしたページだけを縦に連続表示
- 複数PDFのヒットページを1本のスクロール画面に統合
- 各ページに元PDF名・元ページ番号・一致件数を表示
- 検索語に一致した箇所をページ内で黄色表示
- 左側の検索結果クリックで連続表示内の該当ページへスクロール
- 各ページから「1ページ表示」へ切替可能
- 連続表示と1ページ表示をツールバーで切替可能
- 連続表示でも拡大・縮小が可能
- 画面付近のページだけを遅延描画し、ブラウザ負荷を軽減
- 連続表示は最大100ページ（それ以降は1ページ表示で確認）
- v2.1のCanvas描画競合対策を維持

確認方法:
1. 複数PDFを選択して横断検索
2. ヒットページが右側に縦並びで表示されることを確認
3. 右側をスクロールし、近づいたページが順次描画されることを確認
4. 左側の検索結果をクリックし、該当カードへ移動することを確認
5. 各カードの「1ページ表示」で元PDF表示へ切り替わることを確認
6. 「ヒットページ連続表示」で連続画面へ戻れることを確認
7. 連続表示中に拡大・縮小し、表示が再描画されることを確認
