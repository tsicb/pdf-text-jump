PDF Text Jump Viewer v3.1（ワイドレイアウト・サイドバー・幅自動適合）

【GitHubへの反映】
既存の index.html を本ファイルで上書きしてください。
pdfs.json を独自編集している場合は、既存ファイルをそのまま残してください。

【主な改修】
- GitHub Pagesの画面幅をほぼ全てPDF表示へ利用
- 検索結果を開閉式サイドバーへ変更
- サイドバーの開閉状態をlocalStorageへ保存
- 独立していたステータス枠を廃止
- PDF選択数、HITページ数、処理状況を上部バー右側へ移動
- 検索進捗を上部バー最下部の3pxバーへ変更
- PDF操作バーを「表示切替／ページ情報／ズーム」の3領域へ整理
- 横長PDFを表示可能な横幅へ自動適合
- サイドバー開閉やウィンドウ幅変更時も自動再適合
- 手動ズーム後は自動適合を解除し、「幅に合わせる」で復帰
- 連続表示カードの見出し・余白・枠を小型化
- v3.0.1の1ページ表示修正と描画競合対策を維持

【初期動作】
初回は検索結果サイドバーを開いた状態です。
一度閉じると、次回アクセス時も閉じた状態から始まります。
表示倍率は「幅に合わせる」が初期値です。
