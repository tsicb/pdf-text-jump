PDF Text Jump Viewer v3.2（ページ送り・ページ全体表示・モード保持）

【GitHubへの反映】
既存の index.html を本ファイルで上書きしてください。
pdfs.json を独自編集している場合は、既存ファイルをそのまま残してください。

【追加・修正した機能】
- 表示方法を「連続スクロール」「ヒットページ送り」「元PDF表示」の3種類に整理
- ヒットページ送りでは検索結果だけを1ページずつ表示
- 矢印キー、PageUp／PageDown、Space、Shift+Spaceで前後移動
- マウスホイール1操作で前後のヒットページへ移動
- ホイール連続発火によるページ飛ばしを抑えるクールダウン制御
- 「ページに合わせる」を追加し、PDF全体を表示領域内へ収める
- ヒットページ送り・元PDF表示の初期倍率は「ページに合わせる」
- 連続スクロールの初期倍率は「幅に合わせる」
- 表示モードと各モードの倍率設定をlocalStorageへ保存
- サイドバーからページジャンプしても表示モードを勝手に変更しない
- 連続表示上限外のページは通知のみ表示し、ユーザー操作なしで元PDF表示へ切り替えない
- v3.1までの横幅最大化、サイドバー、描画競合対策を維持

【操作の考え方】
- 連続スクロール：複数のヒットページを一覧確認するとき
- ヒットページ送り：検索結果だけを1ページずつ読むとき
- 元PDF表示：ヒットページの前後を含めて元資料を読むとき

【キーボード操作】
前へ：← / ↑ / PageUp / Shift+Space
次へ：→ / ↓ / PageDown / Space

【注意】
- マウスホイールによるページ送りは「ヒットページ送り」だけで有効です。
- 元PDF表示では前後ボタンまたはキーボードで元PDFのページを移動します。
