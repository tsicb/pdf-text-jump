PDF Text Jump Viewer v2.1（描画競合修正版）

配置:
- index.html: リポジトリ直下へ上書き
- pdfs.json: リポジトリ直下（既存設定を継続利用）
- PDF: indeedmarketreports/ 内

今回の修正:
- 連続したページ切替・ズーム時に進行中のPDF.js RenderTaskをcancel()
- 同じCanvasへの複数render()同時実行を防止
- 最新のページ・倍率要求だけを描画するキュー方式へ変更
- getPage()やTextLayer処理中に操作された場合も古い処理を破棄
- PDF切替時は描画停止を待ってから旧PDFをdestroy()
- 検索結果を連続クリックした場合の読み込み競合も抑止

確認方法:
1. 検索結果を開く
2. 「次ページ」を素早く10回程度クリック
3. 前ページ・次ページを交互に連続クリック
4. ズーム＋／－も連続操作
5. PDF画面が黒くならず、最後に要求したページが表示されることを確認
